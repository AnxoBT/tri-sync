# Security policy · Política de seguridad

## Supported versions

Only the latest release of Tri-Sync receives fixes. Please update before reporting.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report them privately through
[GitHub's private vulnerability reporting](https://github.com/AnxoBT/tri-sync/security/advisories/new)
(Security → Report a vulnerability). Include the version, platform and steps to reproduce.
You'll get an answer as soon as possible, and the fix will be published in a new release.

---

## Versiones con soporte

Solo la última versión de Tri-Sync recibe arreglos. Actualiza antes de informar.

## Informar de una vulnerabilidad

Por favor, **no abras una issue pública** para problemas de seguridad. Infórmalos en privado con
el [aviso privado de vulnerabilidades de GitHub](https://github.com/AnxoBT/tri-sync/security/advisories/new)
(Security → Report a vulnerability). Incluye la versión, la plataforma y los pasos para
reproducirlo. Recibirás respuesta lo antes posible y el arreglo saldrá en una nueva versión.
